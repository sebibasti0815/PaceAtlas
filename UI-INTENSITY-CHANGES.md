# Einheitliche Intensitätsanzeige

Die Eingabemaske und die Aktivitätszeilen im bisherigen Verlauf verwenden jetzt `ActivityIntensityVisual.Marker` und `.Brush` als gemeinsame Definition. Die Verlaufszeilen zeigen weiterhin vier Segmente, aber in derselben Farblogik wie die Eingabemaske. Andere Skalen (Allgemeinzustand, Heatmap) bleiben unverändert, da sie andere Messgrößen darstellen.

Build/WinUI-Laufzeittest unter Windows noch erforderlich.
